## PBRCIM

I developed **PBRCIM (Pattern-Based Root Cause Isolation Model)** to analyze failures by tracing the gap between expected behavior and actual system behavior.

The model is used in my diagnostic work and evaluation research around software failures and LLM code reasoning.
